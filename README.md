# Daily Frontier

Small, independently runnable open-source projects with a tested core workflow.
Quality, privacy and maintainability take priority over the number of releases.

| Project | What it does | Runtime | First publication |
| --- | --- | --- | --- |
| [PackDelta](https://github.com/Nova-Lciop-J/daily-frontier-packdelta) | Offline review of file, permission and manifest changes between two npm tarballs; never executes their code. | Python 3.13.15; no runtime dependencies | 2026-09-21 |

PackDelta's initial verified commit is `8b43620af408017c66fb648304234ec8845a03c2`.
[Actual CI run](https://github.com/Nova-Lciop-J/daily-frontier-packdelta/actions/runs/35600011215).
The project is a review aid, not a malware detector or a guarantee of release safety.

Each project contains English and Chinese instructions, tests, synthetic examples,
a license, limitations and maintenance notes. Review checkpoints are planned for
days 1, 2, 3, 5, 30 and 90 after its first successful publication. A check need not
produce a code change. No promises are made about popularity or future features.

## 中文说明

每个项目使用独立仓库，并提供可运行的核心流程、测试、合成样例和中英文文档。
项目质量与隐私保护优先；不合格的候选会暂缓发布，不以仓库数量代替价值。

首个项目 PackDelta 用于离线比较两个 npm 发布包，帮助审核实际发货内容。
它不会执行包内代码，也不需要 API Key；它不能替代秘密扫描或恶意软件检查。

This index contains public project information only.
